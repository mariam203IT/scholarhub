# ScholarHub - Student Scholarship & Opportunity Hub

## Project Overview
ScholarHub is a modern, responsive frontend web application built with React.js and Vite. It serves as an academic portal designed to help university students discover, filter, and track verified global scholarships, internships, and research grants.

## Key Features
- **Multi-Page Navigation:** Built using `react-router-dom` supporting Home, About, Opportunities, My Saved, Dashboard, FAQ, and Contact Us pages.
- **Dynamic Local Storage & Image Upload:** The "My Saved" module allows users to bookmark custom scholarships, attach university logos, and persist data locally using browser `localStorage` and `FileReader` (Base64), ensuring data retention after page refreshes.
- **Interactive Filtering:** Filter available opportunities by category and type.
- **Form Validation:** Client-side validation implemented on the Contact Us form.
- **Modern UI/UX:** Styled using custom responsive CSS inspired by modern design systems (Untitled UI aesthetics).

## Tech Stack
- **Frontend Framework:** React.js (Vite)
- **Routing:** React Router DOM
- **Styling:** Vanilla CSS (Flexbox & CSS Grid)
- **State & Storage:** React `useState`, Browser `localStorage`
- **Version Control:** Git & GitHub
